SONATA — электронный дневник музыкальной школы
================================================

Структура:
index.html         Главная страница с информацией о школе
schedule.html      Расписание занятий
attendance.html    Посещаемость
assignments.html   Домашние задания
grades.html        Успеваемость
profile.html       Личный кабинет
login.html         Вход
register.html      Регистрация
admin.html         Панель администратора
css/style.css      Стили
js/app.js          Логика сайта и демонстрационные данные

Запуск:
1. Распакуйте архив.
2. Откройте папку проекта в Visual Studio Code.
3. Запустите index.html через расширение Live Server.

Демо-аккаунты:
Ученик: student@sonata.ru / sonata2026
Преподаватель: teacher@sonata.ru / sonata2026
Администратор: admin@sonata.ru / sonata2026

Важно:
Это учебная frontend-версия без сервера и базы данных.
Регистрация, пользователи и изменения хранятся в localStorage браузера.
Пароли в этой демонстрационной версии не защищены серверным хешированием.
Роли и ограничения интерфейса предназначены для демонстрации, а не для
защиты реальных персональных данных. Для реального использования потребуется
серверная авторизация и база данных.
